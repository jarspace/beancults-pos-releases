# Beancults POS — Rilis APK Android

Repositori ini khusus menyimpan berkas rilis resmi **Beancults POS** untuk Android (Signed Release APK).

- **Unduh langsung APK terbaru (`.apk`, tanpa `.zip`):**  
  [Beancults-POS-latest.apk](https://github.com/jarspace/beancults-pos-releases/releases/latest/download/Beancults-POS-latest.apk)
- **Daftar seluruh versi rilis:**  
  [Halaman Releases](https://github.com/jarspace/beancults-pos-releases/releases)
- **Aplikasi Kasir Web / PWA:**  
  [pos.beancults.my.id](https://pos.beancults.my.id)

## Catatan pemasangan di HP Android

1. Ketuk tautan **Beancults-POS-latest.apk** di atas (atau melalui tombol **Unduh APK Android** di `pos.beancults.my.id`), lalu buka berkas `.apk` untuk memasang.
2. Untuk cetak struk thermal Bluetooth: pasangkan (*pair*) printer sekali melalui **Pengaturan Bluetooth Android**, lalu pilih nama printer di menu **Pengaturan → Perangkat & Akun** (atau **Printer & Akun**). Koneksi tersambung otomatis saat aplikasi dibuka ulang.
3. Untuk memperbarui ke versi lebih baru, cukup pasang berkas `.apk` terbaru menimpa aplikasi yang sudah ada tanpa menghapus data toko.
